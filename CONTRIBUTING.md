# Contributing to GLIDE

Bug reports and sounds are welcome.

- **Bugs.** Open an issue with what you pressed, what you expected, and what
  happened. The version number on the splash screen (top right) helps a lot.
- **Sounds.** Saved a patch you love? Attach the `.gpat` file from your card's
  `/glide/` folder to an issue. See [`patches/README.md`](patches/README.md)
  for the format.
- **Ideas.** Feature requests are welcome as issues too.

Code pull requests are not accepted.

Everything here is covered by [`LICENSING.md`](LICENSING.md).
