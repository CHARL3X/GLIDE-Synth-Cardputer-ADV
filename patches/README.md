# The author's patch library

A set of `.gpat` sounds rolled, evolved, and played on the author's own GLIDE,
shared here for anyone's card. These are real keepers from real sessions, not
factory output — the same files the author performs with.

## Using them

Copy any of these onto your microSD card into a `/glide` folder (create it at
the card root if it isn't there). On the device: settings → **Load from SD**,
pick one, play. Loading never overwrites your slots — save it to a slot
(`fn`+`shift`+letter) only if you want to keep it on the instrument.

Every file uses the same tagged codec as the ten slots and the SD library, so
they survive firmware updates and travel card-to-card. See the manual's
[Your sounds are yours](../docs/manual.md#your-sounds-are-yours).

**A filename here is exactly the patch name inside it.** That is not decoration:
*Save to SD* names a file from the sound's own name, so if the two disagree,
loading a patch and re-saving it leaves you a second file holding the same
sound. Keeping them equal makes load-then-save a no-op.

## The sounds

Eight of these are the factory bank, so you already have them on the
instrument — they are here so you can put them on a card, hand it to someone,
or fork one without spending a slot.

| sound | what it is | in the bank? |
|-------|------------|--------------|
| **GLIDE** | synth brass on a plain saw: the filter attacks *into* each note, so it swells into its own blat | `q` |
| **ACID** | the resonant 303 squelch. tilt is the wah | `w` |
| **Organ** | drawbar organ, leslie shimmer, near-full sustain. sits *under* a solo | `e` |
| **Taser** | open saw + sub. key-track darkens it as you play up; leaning swells the echo | `r` |
| **Crisp Horn** | bright reed horn that sings its own 7-cent vibrato without you leaning | `t` |
| **Fat Square** | punchy square, bright per-note filter bloom, a noise knock on the attack | `y` |
| **Hollow** | driven square through a *notch* filter — phasey rather than dark | `u` |
| **Big** | highpass square ringing at a 261 Hz corner: hollow and enormous at once | `i` |
| **Backing** | bright buzzy bed, chorus + 1/16 delay + a big hall. tilt is the swell | — |
| **Dry Bed** | the opposite bed: dark detuned saws, gentle, completely dry | — |
| **Slow Tide** | a one-second swell over a sub, screaming highpass, quarter-note regen | — |
| **Nasal Bloom** | pulse through a *bandpass* way up at 7 kHz — thin and vocal, blooms in slowly | — |
| **Fuzzy Comet** | sustaining square, near-instant glide. its reverb tail blooms on the mod envelope *and on pitch bend* — the bend is the comet trail | — |
| **Brass** | saw section: the filter attacks into each note and the mod envelope pushes drive as it opens, hall behind it | — |
| **Raw Acid** | acid taken slow and mean: a 0.3 s swell into drive at 5.5, resonant, on a quarter-note regen | — |
| **Ethereal** | soft triangle pad, long glide, roomy hall — the old `t` | — |
| **Bass** | fat pulse bass, sub for weight, snappy filter pluck — the old `e` | — |
| **Solo** | bright always-gliding square lead, 1/8-triplet delay — the old `r` | — |

The last three were factory presets before the bank was recut; they live here so
nothing you liked went away with the update.
